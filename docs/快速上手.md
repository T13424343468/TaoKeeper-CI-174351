# 快速上手

> 适用版本：TaoKeeper（道管家）1.0.0.0（PC 全能版 v1）。
> 本文档随包交付，与 `docs/MSI打包说明.md`（打包细节）、`docs/操作说明.md`（源码构建与自检台）、`docs/Windows真机首验清单.md`（真机逐条验证）并列，互不替代。

## 一、安装

### 方式 A：MSI 安装包（推荐）

1. 双击 `TaoKeeper-PC-MSI-v1.0.0.msi`（真机构建产物，构建方法见 `docs/MSI打包说明.md`）。
2. 安装向导为微信风格自绘单页流程：欢迎/许可 → 选目录 → 安装，全程微软雅黑、中文文案。
3. 默认安装目录为 `D:\Program Files\TaoKeeper`，可在「选目录」一步修改为任意本地路径（建议路径不含中文与特殊字符）。
4. 安装脚本会在装/卸/升级前先结束运行中的 TaoKeeper 进程，无需手动关闭。
5. 覆盖安装走「先卸后装」；同版本允许原地重装。已装更高版本时提示先在「应用和功能」卸载。

### 方式 B：源码构建

源码包用户参见 `docs/操作说明.md`：解压后双击 `build.bat`（或 `build.ps1`），脚本依次跑 Core / AppKernel / Adapters 三套测试（任一红立即停止、不产出包），再产出构建报告与哈希清单。WinUI 壳（TaoKeeper.App）需在 Windows 真机配合 .NET 8 SDK 编译运行。

## 二、首次启动

1. 安装完成后，从桌面或开始菜单快捷方式启动「道管家 · TaoKeeper」。
2. 启动后进入左侧导航的第一页「总览」。首次启动时各页数据均处于**未测/未扫态**：界面如实显示「尚未体检」「尚未扫描」等文案，不预填任何数字——这是道管家的设计原则：没有扫描过，就不给数。
3. 建议的首轮动作：
   - 进「系统体检」做一次体检，得到六维评分与发现清单；
   - 进「磁盘清理」扫描可清垃圾（清理动作全部先进回收站，可还原）；
   - 进「软件管家」扫描已装软件清单（依赖 winget，缺失时该页如实提示，不影响其他功能）。
4. 界面主题可在「设置」页三选：水墨（默认）/ 天青 / 墨白，全局即时生效。

## 三、导航结构

主窗左侧为 260px 导航栏，交付版共 **12 页**（开发期的「设计说明」入口不随包出现），顺序固定：

| # | 导航页 | 一句话说明 |
|---|---|---|
| 1 | 总览 | 体检评分、可清垃圾、可升级软件三格统计 + 四快捷卡 + 清理账最近三笔 |
| 2 | 软件管家 | 装、升、卸、管，全部官方渠道，装前哈希校验、装后可溯 |
| 3 | 磁盘清理 | 按规则聚合可清项目，清理先进回收站 |
| 4 | 系统体检 | 六维体检，缺项不误扣分 |
| 5 | 性能加速 | 启动项建议（只列不代做）+ 进程占用；启动项清单为页内只读一节 |
| 6 | 内存管理 | 物理/虚拟内存双仪表、趋势、占用排行、页面文件方案 |
| 7 | 驱动安装升级 | 官方渠道清册，装前备份、逐项确认、哈希失配标死 |
| 8 | 弹窗管理 | 规则清单逐条开关、白名单、拦截记录可回溯（不做窗口劫持） |
| 9 | 存储感知 | 定时清理默认关，到点只出确认预览 |
| 10 | 工具箱 | 8 张快捷卡：大文件查找、重复文件、相似图片、右键菜单管理、文件粉碎、进程管理、磁盘空间分析、系统信息 |
| 11 | 桌面挂件 | 常驻桌面一角的内存环图 + 一键清理（须过明细确认浮层） |
| 12 | 设置 | 主题、通用、软件管家、清理与存储、桌面挂件五组开关 |

三个功能子页不在导航条内，由所属页面进入：

- **磁盘空间分析**、**重复文件**：工具箱卡片点击进入（独立页面，数据随工具箱注入）；
- **启动项**：性能加速页内的只读清单一节（改系统的动作统一在性能加速页逐条确认后执行）。

逐页功能与边界（含各页数据来源与未接线状态的如实说明）见 `docs/功能与边界.md`。
