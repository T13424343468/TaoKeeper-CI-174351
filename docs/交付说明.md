## 三、已知限制（如实声明）

1. **WinUI 壳真机编译验证状态**：逻辑层（Core / AppKernel / Adapters）在沙箱全绿（见第四节），但 `TaoKeeper.App`（WinUI 3 壳）依赖 Windows AppSDK，沙箱环境无法编译运行 WinUI 界面——**壳的真机编译、启动、页面导航与渲染均待 Windows 真机验证**，逐条验证项见 `Windows真机首验清单.md`。页面接线以代码与页面注册表为准：截至文档发布时点，交付壳 `PageRegistry` 快照已注册总览页，其余 11 页由集成线完成注册；未注册路由显示如实占位（「本页正在赶工」，无假数据）。
2. **MSI bind 阶段待真机构建**：MSI 打包在沙箱完成结构编译与链接（WiX 5.0.2 + UI 扩展真跑，零错误零新增警告），但 bind 阶段依赖 Windows `msi.dll`，沙箱物理无法完成（收场于 WIX0001，预期内）。**最终 MSI 须按 `tools/msi/build-msi.bat` 在真机构建**；安装/卸载/覆盖升级体验只能真机验证。
3. **运行期数据接线**：垃圾扫描、软件清单、驱动清册、内存快照等运行期数据注入由集成线与真机适配层接线；接线前各页如实显示「尚未扫描/未测」空态，不预填任何数字。
4. **边缘功能最小可用**：驱动管理（备份命令与回滚为文本转述，提权执行待真机）、弹窗管理（只做规则识别与留痕，不做窗口劫持）、工具箱五张卡（相似图片、右键菜单管理、文件粉碎、进程管理、系统信息）未落地，点击只有如实提示；桌面挂件当前为页内示意卡，真实常驻挂件随运行期接线。
5. 合规边界全程不变：清理动作全部经确认、默认进回收站可还原；软件只装官方源、装前哈希校验；页面文件与驱动改动须用户逐次确认。
