# Windows 真机首验清单（定稿 v2，2026-11-05；2026-11-12 增补冲刺交付待验项）

> 用途：TaoKeeper 首包真机验证清单。沙箱逻辑层全绿不代表真机行为正确，以下各项须在 Windows 真机逐条验证。
> 视角：模拟全新用户第一次使用，从安装启动开始走完整流程。
> 约定：每项写清「验证方法 → 预期结果」；预期不符按 Tao 系标准回灌修复，不口头过关。
> v2 定稿：补入三主题与换肤唯一入口、扫描核心双路径（MFT/回退）、静默升级默认关、中文长路径兼容、高 DPI 与多显示器挂件、清理账与白名单真机行为。

## 1. 软件管家：winget 静默安装行为

- 验证方法：在无 winget 或 winget 版本过旧的机器上启动软件管家；选一个开源软件（如 7-Zip）执行安装，观察是否走 `winget install --silent` 通道；再验证 winget 源不可达时的降级路径。
- 预期：有 winget 时全程静默、无捆绑弹窗、装完校验官方哈希；无 winget 或哈希失配时不静默继续，明确提示用户并停止，不装改版、不装全家桶。

## 2. 软件管家：哈希失配处理

- 验证方法：使用测试用损坏包或模拟哈希不一致场景，触发「下载完成 → 哈希校验」流程。
- 预期：校验失败立即删除残留安装包，不进入安装；界面给出「校验失败已阻止」文案与重新下载入口；不得出现任何绕过提示继续安装的路径。

## 3. 驱动升级：WUA 提权流程

- 验证方法：普通权限运行 TaoKeeper，发起一次驱动检测与升级（建议用无风险的更新检查触发）。
- 预期：首次触发时弹出系统 UAC 提权框（文案指向 TaoKeeper 自身）；用户拒绝后不降级静默提权，界面保留「稍后重试」；升级前按文档完成驱动备份，回滚入口可用。

## 4. 内存管理：页面文件修改确认流

- 验证方法：进入内存管理 → 虚拟内存优化，依次走 ①四预设方案之一 ②自定义越界值（如最大<初始）③「完全关闭」。
- 预期：①应用前出现三步确认卡（确认→备份→应用），第 1 步动态显示所选方案与参数；②越界值红色提示且应用按钮禁用；③「完全关闭」必须勾选并弹二次确认，取消自动回退，不写注册表；修改页面文件后按 Windows 要求提示重启生效，重启前不部分写入。

## 5. 备份与回滚

- 验证方法：修改页面文件参数前记录原始值；应用后在确认卡内点击「回滚」。
- 预期：回滚恢复到修改前数值；回滚动作同样要求确认；回滚后无需重启或按提示重启后生效，不出现备份文件残留或损坏。

## 6. 一键清理挂件：常驻与关闭零残留

- 验证方法：开启挂件后检查桌面右下角常驻图标与内存环形图刷新；再在设置页关闭挂件，打开任务管理器核对进程；重开挂件验证功能恢复。
- 预期：挂件常驻且与监控页数据同步；关闭后挂件消失、无任何后台进程残留；重开即恢复；「一键清理」永远先过明细确认浮层，清理走回收站语义（可还原），完成后正确报释放量。

## 7. 弹窗管理：不劫持、可回溯

- 验证方法：启用 1–2 条测试规则，让匹配弹窗出现；再放行白名单进程的弹窗。
- 预期：拦截记录含时间、命中规则、处理动作三要素；白名单优先于规则；引擎绝不出现窗口劫持、注入或全屏遮挡类行为（合规红线）。

## 8. 存储/清理动作：确认与回收站语义

- 验证方法：执行垃圾清理、重复文件清理、存储感知定时任务各一次（用测试目录）。
- 预期：任何清理前必须经用户逐项确认；默认进回收站或白名单机制；存储感知默认关闭、逐项勾选；不做静默删除。

## 9. 安装、卸载与数据位置

- 验证方法：MSI 安装 → 升级 → 卸载 → 重装完整走一遍；安装与运行期间观察数据目录。
- 预期：MSI 直装；数据默认落 D 盘（无 D 盘时明确提示并降级）；卸载移除自启与挂件残留；升级不丢用户配置。

## 10. 静默升级默认关

- 验证方法：安装一个有新版本的软件，观察升级提示行为；再到设置页核对静默升级开关初始状态。
- 预期：默认「关」——每次升级前先展示更新说明与确认入口，不自动后台升级；开启开关后行为符合设计文档口径，且开关状态持久化。

## 11. 扫描核心双路径：NTFS MFT 直读与回退

- 验证方法：NTFS 系统盘上分别跑快扫与普通扫，对照 Windows 内置资源管理器统计同目录文件数与总量；再在非 NTFS 卷（如 FAT32 U 盘）各跑一次。
- 预期：MFT 直读路径结果与回退枚举路径一致（文件数、字节数、大文件标记）；非 NTFS 卷自动走回退路径不报错；两种路径都遵守快扫跳过目录白名单；扫描全程只读，无任何写入被扫描目录的行为。

## 12. 中文与长路径兼容

- 验证方法：在含中文名、空格、超长路径（>260 字符，开启长路径支持的目录）建文件后跑扫描、垃圾识别与重复文件识别。
- 预期：中文与特殊字符文件名显示、统计、哈希均正确；长路径不丢不截断；重复文件识别对中文名文件零误报。

## 13. 高 DPI 与多显示器下的挂件

- 验证方法：100%/125%/150% 缩放下检查挂件大小与清晰度；双显示器环境下拖动挂件跨屏、关闭后重开。
- 预期：各缩放档位无模糊无错位；跨屏位置记忆正确；关闭重开后出现在预期位置；不遮挡任务栏与系统托盘交互。

## 14. 三主题与换肤入口唯一

- 验证方法：在水墨（默认）/天灰/墨夜三主题间切换，逐一检查九个模块页与挂件配色；确认除设置页外无第二个换肤入口。
- 预期：三主题全部正常渲染、对比度可读；默认即水墨；换肤入口唯一，切换零残留（重启后主题保持）；所有确认卡、浮层在深色主题（墨夜）下同样可读。

## 15. 清理账与白名单真机行为

- 验证方法：完成一次垃圾清理后查看清理账记录；把一个测试目录加入白名单后再跑垃圾扫描与存储感知。
- 预期：清理账如实记录每次动作（时间、对象、结果、可还原入口）；白名单目录在所有清理通道（手动清理、存储感知、挂件一键清理）中都被跳过；从回收站还原后文件完好。

## 16. 冲刺交付补充验证项（2026-11-12 全测报告第 9 层，随包必验）

- **C++ 扫描核心测试**：真机 `cmake --build native/TaoKeeperScan` 后 `ctest` 逐套件跑 5 个套件（scan_core / mft_parser / mft_tree / mft_stream / mft_agg_incr）。预期：全过、零失败。
- **WinUI 壳编译与导航**：`build.bat` / `build.ps1` 构建后启动，逐个点过 11 条注册路由（软件管家、磁盘清理、体检、性能加速、内存、驱动、弹窗、工具箱、挂件、设置、总览）+ 工具箱内空间分析/重复文件/存储感知三卡。预期：页面加载无崩溃、空态如实显示。
- **MSI 全流程**：真机跑 `tools\msi\build-msi.bat`，按《操作卡-真机出包一条龙》28 格走：out 目录仅 1 个 msi（文件名全 ASCII）→ 安装（默认 D:\Program Files\TaoKeeper，可改）→ 卸载干净 → 覆盖升级。
- **build.ps1 真跑**：pwsh 7.4+ 执行 `build.ps1`，预期 EXIT=0、版本戳正确（上轮沙箱曾 EXIT=0，本轮环境重置未复跑）。
- **哈希三元组终核**：最终包出齐后跑哈希脚本，核对字节数 + SHA-256 + 顶层清单一致。
- **操作卡前置**：出包前按操作卡「开工前总检」3 项过完才动工。
