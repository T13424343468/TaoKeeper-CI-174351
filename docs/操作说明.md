## 一、环境前置

| 项 | 要求 | 检查方法 |
|---|---|---|
| 操作系统 | Windows 10 / 11 x64 | — |
| .NET SDK | x64 版，8 或更高（8 必装建议；仅更高版本如 10.x 时脚本自动滚动前向运行，报告中会注明） | `dotnet --version` 显示 8.x 或更高 |
| winget | 建议可用（「软件管家」自检需要；缺失只影响该通道，不影响构建） | 终端运行 `winget --version` |
| CMake 3.20+ 与 VS2022 Build Tools | 可选（编译 C++ 核心用；不装则加 `-SkipNative` 跳过） | `cmake --version` |

.NET 8 SDK 下载：<https://dotnet.microsoft.com/download/dotnet/8.0>（选 Windows x64 SDK）。机器上已装更高版本（如 .NET 10 SDK）也可以直接跑：脚本会自动滚动前向，但建议仍装 8 完全对齐。

## 二、一键构建（两步）

1. 把 zip 解压到任意本地目录（建议路径不含空格与中文）。
2. **双击 `build.bat`** 即可（推荐）：窗口全程保留，出错不会一闪而过，跑完按任意键再关。
   - 想跳过 C++ 核心（没装 CMake）：在 cmd 里运行 `build.bat -SkipNative`。
   - 习惯命令行的话，等价写法（在解压目录打开 PowerShell 或 cmd 运行）：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

没装 CMake 时加开关跳过 C++ 核心：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -SkipNative
```

脚本会依次：检查 .NET 8 SDK → 依次跑 Core / AppKernel / Adapters 三个测试工程（任一红立即停止、不产出任何包）→ 构建 TaoKeeper.Harness 自检台 → （可选）CMake 编译 C++ 核心并跑 ctest → 在 `dist\<时间戳>\` 下产出：

- `构建报告.txt`（每步结果全记录）
- `哈希清单-SHA256.txt`（产物文件逐一 SHA-256）

**判定**：构建报告里全绿 = 构建通过；出现任何红字请先停下，把报告原文回传大光。

## 三、真机自检台（只读，零写动作）

构建通过后，在解压目录运行（PowerShell 或 cmd）：

```powershell
dotnet run --project src/TaoKeeper.Harness -- all
```

也可以分通道单独跑（方便定位）：

```powershell
dotnet run --project src/TaoKeeper.Harness -- list-software
dotnet run --project src/TaoKeeper.Harness -- list-drivers
dotnet run --project src/TaoKeeper.Harness -- driver-updates
```

各通道说明（全部只读，不做任何安装/升级/删除）：

| 通道 | 内容 |
|---|---|
| list-software | 调 winget 列出已安装软件与可升级清单（只列，不装） |
| list-drivers | 调 pnputil 枚举第三方驱动并解析清册（只读） |
| driver-updates | 走 Windows 更新 COM 接口搜索驱动更新候选（只搜，不装） |
| all | 三通道连跑（默认） |

**判定**：全部通过时输出「全部通道通过」、退出码 0；任一通道报红时退出码为 2，并直接给出报红原因。

## 四、把结果回传大光

无论全绿还是报红，请把以下内容**全文（或截图）回传**给大光，用于真机回流验证：

## 五、包内内容速览

- `build.bat`：一键构建入口（双击即可，窗口保留不闪退）。
- `build.ps1`：一键构建脚本本体（build.bat 内部调用）。
- `src/`：Core（纯 .NET 业务核心）、AppKernel（导航/主题/设置）、Adapters（winget 与驱动适配层）、Harness（真机自检台）、App（WinUI 壳占位，本包不含界面）。
- `tests/`：三个工程的单元测试。
- `native/`：C++ 核心（MFT 扫描、路径聚合）与 C ABI 导出层，CMake 构建。
- `docs/`：设计文档。
