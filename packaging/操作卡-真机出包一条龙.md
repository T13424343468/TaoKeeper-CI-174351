# 真机出包一条龙操作卡（TaoKeeper PC-FULL-V1 / MSI 1.0.0.0）

> 使用者：真机出包操作者（P4 窗口 01:30–02:10）。
> 原则：**一步一核对格**——每步执行后先勾核对项再进下一步；任何一格打不上勾 = 停，按红灯口径回报，不凑合往下走。
> 全程离线：不下载任何运行时（第九章 6）。

## 〇、开工前总检（3 项，全过才动工）

| # | 动作 | 核对格 |
|---|---|---|
| 0.1 | 前置环境：Windows 10 1809+、.NET 8 SDK、`dotnet tool list -g` 有 wix（5.0.x）、`wix extension list -g` 有 WixToolset.UI.wixext（版本与 wix 对齐） | ☐ |
| 0.2 | 工作树版本六处核对：`package-manifest.md` 〇节表格逐处 grep，全为 PC-FULL-V1 / 1.0.0.0 | ☐ |
| 0.3 | 工作目录确认：cd 到 TaoKeeper-Package-v1 工作树根，`dir` 确认 src/、tools/msi/、docs/ 在位（防跑错树，第八章 29「打包前核对工作目录」） | ☐ |

## 一、发布载荷（离线 publish）

| # | 命令 / 动作 | 核对格 |
|---|---|---|
| 1.1 | `dotnet publish src\TaoKeeper.App -c Release -r win-x64 --self-contained false -o tools\msi\publish` | ☐ |
| 1.2 | 核对 `tools\msi\publish\TaoKeeper.App.exe` 存在 | ☐ |
| 1.3 | 错误统计：构建输出 `grep -c ': error'`（或肉眼逐行）见 0 才算过，禁止只看尾部（避坑清单第 7 条） | ☐ |

## 二、构建 MSI

| # | 命令 / 动作 | 核对格 |
|---|---|---|
| 2.1 | 运行 `tools\msi\build-msi.bat`（可传参指定 publish 目录；默认 tools\msi\publish） | ☐ |
| 2.2 | 脚本输出 `[OK] MSI built: out\TaoKeeper-PC-MSI-v1.0.0.msi`，EXIT=0 | ☐ |
| 2.3 | 脚本自检 `[CHECK] msi files in out: 1`（out 单 msi，第九章 1） | ☐ |
| 2.4 | 文件名核对：`out\` 下唯一 msi 名为 `TaoKeeper-PC-MSI-v1.0.0.msi`，全 ASCII 零中文零空格 | ☐ |

## 三、组装 out/（按 out-plan.md）

|---|---|---|

| 3.2 | 建快照 `out\TaoKeeper-src-v1.0.0\`：按 out-plan 第三节**排除清单**拷贝（排除 bin/obj、native build、publish、out、.precheck、dist、日志） | ☐ |

| 3.5 | out 顶层清点：**1 个 msi + hashes.txt（下一步生成）+ package-manifest.md + docs\ + TaoKeeper-src-v1.0.0\**，无 zip/7z/第二个 msi | ☐ |

## 四、生成哈希清单

| # | 命令 / 动作 | 核对格 |
|---|---|---|
| 4.1 | 拷 `packaging\make-hashes.bat` 到 `out\`，运行之（或在 out 内 cmd 执行） | ☐ |
| 4.2 | 输出 `[OK] files hashed: N`，N = out 文件总数 − 1（不含 hashes.txt 自身） | ☐ |
| 4.3 | 抽验格式：打开 hashes.txt，msi 行在最前（排序首位），小写 64 位十六进制 + 两空格 + 正斜杠路径 | ☐ |
| 4.4 | 记录 msi 字节数（资源管理器或 `for %f in (out\*.msi) do @echo %~zf %f`）——三元组之一 | ☐ |
| 4.5 | **删除 out 内的 make-hashes.bat**（构建期工具不进交付包；或拷入前先在 out 外运行） | ☐ |

> 备选：沙箱侧生成可用 `make-hashes.sh`（同目录同算法，输出格式一致，已在沙箱 pwsh 真跑对拍）。

## 红灯口径（任一触发即停）

- 版本六处任一不一致 → 停，回报调度核心，不自行改版本号（禁改已绿产物）。
- build-msi.bat 报 publish 载荷缺失或 wix 编译错 → 停，贴 [ERROR] 行回报，不猜原因。
- out msi 数 ≠ 1 → 停（脚本已拦截），清 out 重组装，不手改文件名。
- 快照计数或内容与 manifest 不符 → 停，回报差异清单。
- 哈希失败 / 非 ASCII 文件名被脚本拦截 → 停，回报文件名。
