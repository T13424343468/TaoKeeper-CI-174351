# packaging/ — K 线出包准备资产（2026-11-12，P4 窗口）

本目录是**出包准备线（K 线）**的全部交付物，供真机出包动作（P4，01:30–02:10）直接取用。
本线**不改** `src/`、`tools/`、`docs/`、build 脚本任何文件；全部为新增准备资产。

## 文件索引

| 文件 | 用途 |
|---|---|
| `out-plan.md` | out/ 交付目录规划（结构、组装规则、禁止事项） |
| `package-manifest.md` | 源码清单：包内每个文件/目录的来源与用途，逐项列明（交付时拷入 out/ 顶层） |
| `hashes-spec.md` | hashes.txt 格式规范（SHA-256 清单） |
| `make-hashes.sh` | SHA-256 清单生成脚本（Linux 版，沙箱/接收端可用） |
| `make-hashes.bat` | SHA-256 清单生成脚本（Windows 版，纯 ASCII + CRLF） |
| `操作卡-真机出包一条龙.md` | 真机一条龙步骤：build-msi.bat → 哈希 → 自检清单，一步一核对格 |
| `汇报模板-出包汇报.md` | 出包汇报结构模板（全测绿后即填即发） |

## 使用方式（真机操作者视角）

1. 先读 `操作卡-真机出包一条龙.md`，按步骤执行；
2. out/ 目录结构与组装规则见 `out-plan.md`；包内文件口径查 `package-manifest.md`；
3. 哈希清单怎么生成、怎么验，见 `hashes-spec.md`（脚本在本目录）；
4. 出包完成后按 `汇报模板-出包汇报.md` 填写并回传。

## 边界提醒

- 本目录资产是**构建期工具与口径文档**，不进 out/ 交付包（唯一例外：`package-manifest.md` 拷入 out/ 顶层作为交付清单）。
- out/ 实体目录由真机脚本与操作卡组装，沙箱内**不落 out/ 实体文件**。
- 版本口径全局一致：**PC-FULL-V1 / 1.0.0.0（2026-11-12）**，详见 `package-manifest.md` 头部版本核对表。
